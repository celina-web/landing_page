# PFO1 – Landing Page personal

Este proyecto es mi primera entrega para la materia Desarrollo de Sistemas Web: Frontend. Consiste en una landing page personal. Todo está desarrollado con HTML y CSS puro, aplicando los conceptos de: semántica, flexbox, grid, responsive, tipografías de Google y animaciones.

## Estructura de archivos

- `index.html` – estructura completa de la landing.
- `style.css` – todos los estilos, con variables CSS, flexbox, grid y animaciones.
- `assets` - carpeta para imágenes.
---

## Decisiones de diseño

- **Inspiración visual:** tomé como referencia la estética del videojuego *Stardew Valley*.
- **Maquetación:** elegí **Flexbox** para la navegación, el header y las secciones de presentación y contacto, porque necesitaba alinear elementos en una sola dimensión y que se acomodaran fácilmente. Para las tarjetas de habilidades usé **Grid** con `auto-fit`, porque quería que se distribuyeran en varias columnas de forma equitativa y automática al cambiar el ancho de pantalla.
- **Responsive:** trabajé con unidades relativas (`rem`, `%`, `vw`) y media queries para que la página se vea bien en celulares, tablets y escritorios. Además, el menú se vuelve flexible y las imágenes se escalan sin romper el diseño.
- **Animaciones:** agregué una animación de parpadeo (con `@keyframes`) en el ícono del logo para darle un toque “pixel vivo”. También hay transiciones suaves en tarjetas, botones e imágenes al pasar el cursor.
